# Wavora — Core Modules

This directory contains the shared core modules:

- `common` — shared constants and config
- `data` — repositories, database (SQLDelight), DataStore
- `domain` — business models, use cases, interfaces
- `media/media-jvm` — VLC player adapter for Desktop
- `media/media3` — ExoPlayer adapter for Android
- `service/kotlinYtmusicScraper` — YouTube Music API scraper
- `service/lyricsService` — lyrics fetching and parsing
- `service/spotify` — Spotify Canvas and lyrics
- `service/kizzy` — Discord Rich Presence
- `service/aiService` — AI song suggestions
